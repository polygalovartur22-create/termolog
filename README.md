# Термологистика — готово к хостингу

Это статический сайт. Никакой сборки не нужно — можно сразу заливать на любой хостинг.

## Как захостить

### Вариант 1 — Vercel / Netlify (рекомендую, 2 минуты)
1. Зайти на vercel.com или netlify.com
2. Перетащить весь архив целиком (или подключить через GitHub)
3. Получить готовый адрес вида `your-site.vercel.app` — можно подключить свой домен

### Вариант 2 — обычный хостинг (Reg.ru, Beget и т.п.)
1. Залить **содержимое** этой папки в корень сайта (`public_html` / `htdocs` / `www`)
2. `index.html` должен лежать в корне
3. Открыть домен — всё работает

### Вариант 3 — GitHub Pages
1. Залить содержимое папки в репозиторий
2. Settings → Pages → Source: main branch / root
3. Готово

## Что внутри
- `index.html` — главная страница
- `parts/*.jsx`, `app.v2.jsx`, `tweaks-panel.jsx` — компоненты React
- `mp5*.jpg`, `mp5*.png` — изображения (логотипы партнёров, фото)

## Важно
- Не переименовывать файлы — пути внутри `index.html` жёсткие
- Сохранять структуру папок (`parts/` должна остаться рядом с `index.html`)
- Сайт использует React и шрифты с CDN — нужен интернет на устройстве посетителя (как у любого современного сайта)
