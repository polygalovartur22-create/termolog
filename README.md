# Термологистика — готовый сайт для хостинга

Статический сайт. Никакой сборки не нужно — заливай как есть.

## Как захостить

### Vercel / Netlify (2 минуты, рекомендую)
1. Зайди на vercel.com или netlify.com
2. Перетащи всю папку или этот ZIP
3. Получишь адрес `*.vercel.app` / `*.netlify.app` — можешь подключить свой домен

### Обычный хостинг (Reg.ru, Beget и т.п.)
1. Залей **содержимое** этой папки в корень сайта (`public_html` / `htdocs` / `www`)
2. `index.html` должен лежать в корне
3. Открой свой домен — всё работает

### GitHub Pages
1. Залей содержимое в репозиторий
2. Settings → Pages → Source: main / root
3. Готово
