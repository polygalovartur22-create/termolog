# Термологистика — готовый сайт для хостинга

Статический сайт. Сборка не нужна — заливай как есть.

## Как захостить

### Vercel / Netlify (рекомендую)
1. Зайди на vercel.com или netlify.com
2. Перетащи всю папку или ZIP
3. Получишь адрес — можно подключить свой домен (termolog.pro)

### Обычный хостинг (РЕГ.РУ, Beget и т.п.)
1. Залей **содержимое** этой папки в корень сайта (`public_html` / `www`)
2. `index.html` должен лежать в корне
3. Открой домен — всё работает

## Страницы
- `index.html` — главная
- `cases.html` — кейсы
- `privacy-policy.html` — Политика обработки персональных данных
- `cookie-consent.html` — Согласие на обработку cookie

## Соответствие 152-ФЗ (реализовано)
- Cookie-баннер при первом визите (с выбором, сохраняется в браузере)
- Обязательный чекбокс согласия в форме заявки (без него форма не отправляется)
- Ссылки на правовые страницы в футере всех страниц

## Не переименовывай файлы
Пути внутри HTML жёсткие. Папку `parts/` держи рядом с `index.html`.
